From Object Detection to Pixel-Level Understanding

represents in the driving scene. My Project uses semantic segmentation because autonomous driving
needs dense pixel-level scene understanding.

================ SLIDE 4 of 8 ================

     FRRN-A Technique
What makes FRRN-A unique?

It preserves full-resolution spatial
detail while also learning deep
scene context. It is useful for
preserving object boundaries.
In this project, FRRN-A classifies
each pixel into a scene category.
• Full resolution stream keeps
    road/object boundaries
    sharper.
• Pooling streams learns overall
    scene context.
• Residual connections support
    stable deep training.

From Legacy Code to Trained FRRN-A Model


                                                                                Dataset: Cityscape/Darmstadt
                                                                                Input: 320 X 640 crops
                                                                                Batch size: 1
                                                                                Training: 100 epochs
                                                                                Model: FRRN-A, ~17.7M Parameters
                                                                                Output: Saved Checkpoints + prediction masks

                                                                                100 Epochs was chosen as a practical
                                                                                balance between visible learning,
                                                                                convergence, dataset size and available
                                                                                GPU time.
